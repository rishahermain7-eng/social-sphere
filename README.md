# SocialSphere

A full-stack social media platform built with React, Node.js, Express, and MongoDB.

## Overview

SocialSphere allows users to create accounts, share posts, upload images, interact with posts, and manage their profiles through a clean and responsive social media interface.

## Features

- User registration and secure login
- JWT-based authentication
- Profile picture upload and update
- Create text, image, or text + image posts
- Public social feed
- Like and unlike posts
- Add and view comments
- Poll and feeling options while creating posts
- Persistent data storage with MongoDB
- Responsive dark editorial UI

## Tech Stack

### Frontend
- React.js
- Vite
- React Router
- Material UI Icons
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs
- Multer
